# Example-image attribution

The README images are actual Bricksmith renders of models assembled from the official LDraw community library. Geometry was placed, rotated and colored for each model; the original source files were preserved.

- `shuttle.png`: 124 placements, rendered from the included [catalog example](../../examples/catalog/).
- `volvo-suv.png`: 301 placements, a stylized SUV interpretation.
